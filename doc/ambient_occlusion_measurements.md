# Замеры SSAO и передач MG-13

Локальная функциональная проверка: Windows, Release, SceneBaseSample, NVIDIA GeForce RTX 4060 Ti. Во втором прогоне GPU 1 — **WARP**, программный адаптер. Размер рендера в обоих логах — **634×611**, камера начальная, режим `lit`, radius=0,5, blur включён. Сцена загружается асинхронно. Два прогона выполнены последовательно по 45 секунд; captures, чтение карт и дополнительный GPU 0 reference выключены.

Это проверка измерительной инфраструктуры. Здесь нет результатов аппаратной пары и вывода о выигрыше производительности. WARP исполняет работу программно; его длительности не характеризуют вторую физическую видеокарту.

## Копирование на COPY-очередях

Частота каждой очереди получена через `GetTimestampFrequency`: GPU 0 — **1 000 000 000 Гц**, WARP — **10 000 000 Гц**. Поддержка COPY timestamps обнаружена на обоих устройствах. Для normals/depth направление `0→1`, для результата `1→0`.

Каждая строка ниже содержит 60 измерений после исключения первых 10 кадров профайлера. Полные CSV содержат **207 проверенных пар**: 69 отправок normals, 69 depth и 69 результата. Для всех пар проверены направление и `/sum = /src + /dst` с учётом округления до 0,0001 мс. Записаны и проверены калиброванные `/span`.

| Передача | Часть | GPU | Среднее, мс | Медиана, мс | P95, мс |
| --- | --- | --- | ---: | ---: | ---: |
| normals | src | 0 | 0,4072 | 0,4294 | 0,4337 |
| normals | dst | 1 | 94,3425 | 92,7246 | 104,3433 |
| normals | sum | 0→1 | 94,7497 | 93,1576 | 104,7714 |
| normals | span | 0→1 | 94,9093 | 93,3039 | 104,9317 |
| depth | src | 0 | 0,4076 | 0,4301 | 0,4358 |
| depth | dst | 1 | 94,2002 | 92,6597 | 103,8382 |
| depth | sum | 0→1 | 94,6078 | 93,0901 | 104,2702 |
| depth | span | 0→1 | 94,7472 | 93,2357 | 104,4184 |
| AO result | src | 1 | 93,4544 | 92,1518 | 101,8910 |
| AO result | dst | 0 | 0,1171 | 0,1230 | 0,1240 |
| AO result | sum | 1→0 | 93,5714 | 92,2296 | 102,0143 |
| AO result | span | 1→0 | 93,6597 | 92,3184 | 102,1021 |

`/sum` складывает две GPU-длительности одной передачи. `/span` переносит обе COPY-шкалы в QPC и измеряет интервал от начала копии отправителя до конца копии получателя, включая промежуточное ожидание. Он не включает ожидание источника до первого timestamp. Длительности разных передач/проходов нельзя механически складывать в длительность кадра: очереди могут перекрываться.

## Воспроизведение и файлы

```powershell
./tools/scripts/run_ssao_demo.ps1 -Device primary -Mode lit -Profile -CaptureFrame 0 -Seconds 45 -Label copy
./tools/scripts/run_ssao_demo.ps1 -Device warp -Mode lit -Profile -CaptureFrame 0 -Seconds 45 -Label copy
python tools/scripts/summarize_ssao_timings.py `
    build/ssao-runtime/lit-profile-copy-timings.csv `
    build/ssao-runtime/warp-lit-profile-copy-timings.csv `
    --warmup-frames 10 --output build/ssao-runtime/mg13-copy-measurements
```

Локальные исходные данные: `build/ssao-runtime/lit-profile-copy*`, `warp-lit-profile-copy*`. Сводка с проверкой пар — `mg13-copy-measurements.json` и `.md`. Логи запуска — `build/ao-copy-primary-profile-run.log`, `ao-copy-warp-profile-run.log`.

После добавления COPY-замеров: SceneBaseSample Release собран; тесты Render — **84 passed, 3 skipped из 87**; самостоятельный Debug — **80 passed, 3 skipped из 83**. Новый `ProfilerLivesUntilBothCopyQueuesDrain` проверяет совпадение tickets и удержание observer до завершения обеих очередей. Шейдеры в этом изменении не менялись; предыдущая проверка — 11/11.

В этих двух запусках раннее падение при остановке не повторилось. Известная гонка асинхронной загрузки текстур после shutdown не объявляется исправленной; остаётся и прежняя ошибка сохранения `cache/dx12.cache`. Общий лист Google Sheets «Замеры» этим изменением не редактировался: результаты зафиксированы в этом документе и описании PR.
